# Plan backlinks Marchéo (créé le 5 novembre 2026)

Un backlink est un lien vers marchéo.fr posé sur un autre site. Pour Google, c'est le signal de confiance qui manque le plus aujourd'hui : le blog compte plus de 40 articles, mais presque aucun site extérieur ne parle de Marchéo. Pour les IA, c'est la même chose : ChatGPT a répondu le 5 novembre qu'il n'avait « pas suffisamment d'informations fiables » sur Marchéo.

Règle de base : uniquement des liens obtenus honnêtement. Pas d'achat de liens, pas de réseaux de blogs, pas d'annuaires « spam » à 200 inscriptions : Google pénalise ces pratiques et le site peut perdre tout son trafic.

Les messages prêts à envoyer sont dans `seo/cibles-mentions.md` (section « Messages types ») et les textes de fiche dans `seo/fiches-annuaires.md`. Rien n'est envoyé automatiquement : Paul envoie lui-même.

Ce type d'outil est souvent cité par les blogs et les CMA, bien plus qu'un article. Proposition : le calculateur de commission en premier (il sert aussi les articles comparatifs).
- **Rédiger les articles invités** de l'action 6 et le communiqué de l'action 9, prêts à envoyer.
- **Lien « Créé avec Marchéo »** en bas des boutiques des commerçants : à vérifier dans le code. Il ne compte comme backlink que si une boutique est publiée sur le nom de domaine du commerçant (pas sur marchéo.fr). Si c'est le cas, un petit lien discret dans le pied de page apporte un lien par client. À décider par Paul, car cela touche les boutiques des clients.
